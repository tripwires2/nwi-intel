# NWI Intel

Northwest Indiana Local Intelligence Dashboard for **Lake**, **Porter**, and **LaPorte** Counties.

Interactive map with emergency layers, live National Weather Service conditions, crime hotspots, infrastructure, and a detailed Area Study export.

## Live Demo

Once GitHub Pages is enabled, the site will be available at:

**https://tripwires2.github.io/nwi-intel/**

## Features

- County tabs (Lake / Porter / LaPorte)
- Live NWS weather and alerts
- Toggleable map layers (crime, flood, hospitals, fuel, EMS, infrastructure, routes, distance rings, and more)
- Layer presets (Flood Response, Severe Weather, Daily Awareness)
- Address search
- Custom markers
- Detailed Area Study with print option
- Mobile-friendly layout

## Notes

- Crime layer uses approximate city-level rankings from public sources (not real-time).
- Civilian awareness tool only — not official guidance.

## Local Use

Open `index.html` in any modern browser.
